Cyclone is a full-stack web application that generates personalized cycling routes using a combination of modern routing engines and AI-assisted decision making. Built for the UPenn MCIT SPARC 2025 Challenge, Cyclone blends algorithmic routing with human-centric preferences to create rides that feel intentional, not generic.

Whether you want a scenic loop, hill-heavy training ride, or bike-lane-optimized commute, Cyclone adapts to how you ride.

---

## Why Cyclone?

Most routing tools optimize for shortest or fastest paths. Cyclone optimizes for experience.

- Multiple routing engines can be compared and blended
- AI assists with preference interpretation and fallback logic
- Routes are evaluated for distance, elevation, and ride style
- Users can save, export, and revisit rides

This project focuses on system design, API orchestration, and human-in-the-loop routing, not just map rendering.

---

## Features

- AI-assisted route generation using OpenAI
- Multi-engine routing with GraphHopper, Valhalla, and custom OSM logic
- Interactive mapping with Leaflet
- Route analytics including distance, elevation gain, and GPX export
- User authentication, profiles, and saved routes
- Responsive, mobile-first UI built with React and TailwindCSS

---

## How the AI Works

Cyclone uses AI as a decision-making and orchestration layer, not as a replacement for traditional routing algorithms. User preferences such as ride style, distance, elevation tolerance, and infrastructure priorities are interpreted by the AI and translated into a structured routing specification. This allows Cyclone to resolve ambiguity in human intent and normalize high-level descriptions into parameters that deterministic routing engines can understand.

The AI then helps guide routing engine selection, parameter tuning, and fallback behavior across GraphHopper, Valhalla, and custom OSM-based routing logic. Candidate routes are evaluated using objective metrics such as distance deviation and elevation gain, with AI assisting only where tradeoffs are non-obvious. All final routes are generated by deterministic engines using real map data, ensuring reliability while retaining flexibility in how rider intent is interpreted.

## Quick Start

### Prerequisites
- Node.js 18+
- Python 3.8+

### Setup

```bash
git clone <your-repo-url>
cd cyclone

cd client
npm install

cd ../server
npm install
pip3 install -r requirements.txt

node server/setup.js

cd ..
./start-dev.sh

## Configuration

### Environment Variables
Create a `.env` file in the project root:

```bash
# Required API Keys
GRAPHHOPPER_API_KEY=your_graphhopper_key_here
OPENAI_API_KEY=your_openai_key_here

# Optional API Keys
GEOAPIFY_API_KEY=your_geoapify_key_here  # Optional, for enhanced geocoding
OPENAI_MODEL=gpt-4o  # Optional, defaults to gpt-4o

# Server Configuration
PORT=3000
NODE_ENV=development
DATA_DIR=./server/databases  # Optional, defaults to ./server/databases
FRONTEND_ORIGIN=http://localhost:5173  # CORS origin for frontend

# Frontend Configuration (Vite uses VITE_ prefix)
VITE_API_BASE_URL=http://localhost:3000
# Note: REACT_APP_API_BASE_URL is also supported for backward compatibility
```

### API Keys Setup
1. **GraphHopper API**: Get your free key at [graphhopper.com](https://www.graphhopper.com/)
2. **OpenAI API**: Create an account at [platform.openai.com](https://platform.openai.com/)

**Note**: The setup script (`node server/setup.js`) will automatically create a `.env` template and validate your API keys.

### Code Examples

#### Route Generation
```javascript
// Generate a custom route via API
const response = await fetch('http://localhost:3000/api/generate-custom-route', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    start_lat: 39.9526,
    start_lon: -75.1652,
    target_distance: 25,
    route_type: "scenic",
    avoid_hills: false,
    use_bike_lanes: true,
    unit_system: "imperial"
  })
});
const route = await response.json();
```

#### User Authentication
```javascript
// Login user via API
const response = await fetch('http://localhost:3000/api/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({
    username: "cyclist123",
    password: "securePassword"
  })
});
const user = await response.json();
```

## API Endpoints

### Authentication
- `POST /api/register` - User registration
- `POST /api/login` - User login
- `POST /api/logout` - User logout
- `GET /api/status` - Check authentication status

### Routes
- `POST /api/generate-custom-route` - Generate new route
- `GET /api/routes` - Get user's saved routes (requires authentication)
- `POST /api/routes/save` - Save a route (requires authentication)
- `GET /api/routes/user/:username` - Get routes by username

### User Profiles
- `GET /api/user/profile` - Get current user's profile (requires authentication)
- `PUT /api/user/profile/:id` - Update user profile with optional avatar upload (requires authentication)
- `GET /api/user/profile/:username` - Get profile by username

### Geolocation
- `GET /api/location` - Get user's location based on IP address
